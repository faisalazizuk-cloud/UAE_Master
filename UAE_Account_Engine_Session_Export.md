## Key Technical Details

### Google Sheet Structure
- **Spreadsheet ID:** `1AjLi9qj0sh-ajoUmiEWrQ4aPhakEwe2S2RK4SptXNhg`
- **Master Ranked gid:** `1926154775`
- **Account Plan column:** D (HYPERLINK formulas)
- **Key Personas column:** F (HYPERLINK with `#gid=XXXX` anchors)
- **Notion Brief column:** E

### Automation Methods Used
- **Playwright over CDP** — for direct Google Sheets cell editing (typing formulas, keyboard navigation)
- **Google Sheets gviz/tq CSV export endpoint** — for reading data without API keys
- **Google Drive folder listing** — for discovering Slides URLs
- **Clearbit Logo API** — for company logos (`https://logo.clearbit.com/{domain}`)
- **Exa/Brave/Bing web search** — for LinkedIn URL lookup

### Important Constraints (User-Specified)
- Do NOT delete anything from the sheet unless explicitly told to
- Do NOT touch the P: FAB tab
- Do NOT put anything in the Notion Brief column except actual Notion document links
- Always confirm with the user before writing to the sheet

## How to Replicate This Workflow

1. **Access required:** Google account with edit access to the UAE Account Engine sheet + Google Drive folder containing account plan slides
2. **Tools needed:** Python 3.12+, Playwright, python-pptx
3. **Key endpoints:**
   - Sheet CSV export: `https://docs.google.com/spreadsheets/d/{id}/gviz/tq?tqx=out:csv&gid={gid}&range={range}`
   - Sheet cell editing: Via Playwright CDP connection to Chrome with Google account logged in
   - Slides URL format: `https://docs.google.com/presentation/d/{id}/edit`
4. **Brand assets:** Cognition palette (#1A1F2E, #4ECDC4, Inter Tight font)
